# AGENTS.md

micro-lc 2 shell with a React navigation bar, for the MFE Orchestrator. README.md explains the why;
these are the rules that keep it working.

## Commands

- `pnpm install`, `pnpm dev` (port 5173), `pnpm build` (→ `dist/`), `pnpm typecheck`,
  `pnpm preview` (port 4173). pnpm 12 via `packageManager`, Node 24 LTS.
- Build needs `VITE_MFE_BACKEND_URL` and `VITE_MFE_PROJECT_ID` (`.env`, see `.env.example`).

## Invariants

- `configure()` stays the first statement of `src/main.tsx`, before anything calls `remoteUrl()`.
- Remote entries come only from `remoteUrl('<slug>')` in `src/microlc-config.ts`. Never write a
  remote URL in code or config; never parse or rebuild the URL it returns.
- Parcels are declared as `entry: { scripts: [url] }`: the remote's entry is one self-contained UMD
  file. Do not switch to an HTML entry unless the remote ships one.
- `src/shared-react.ts` must run before micro-lc mounts anything. The globals `React`, `ReactDOM`,
  `ReactJSXRuntime` are a contract with the parcels' UMD `globals`: renaming one breaks them.
- Create `<micro-lc>` from markup (`innerHTML`), not `document.createElement()` (its constructor
  appends children), and set `config` in the same task.
- Navigate with micro-lc's `getApi().router.goToApplication(id)`, not `history.pushState()`.
- Keep `<base href="/">` in `index.html` in line with where the host is served: micro-lc resolves
  routes against it.
- `public/micro-lc/` is generated by `vite.config.ts` from `node_modules`; do not edit or commit it.
- The `paths` alias for `@micro-lc/interfaces/v2` in `tsconfig.json` works around a broken
  `exports` entry upstream; keep it until the package fixes it.

## Verify a change

`pnpm build`, then run the remote (`pnpm build && pnpm preview` in template-microlc-react-remote), a
mock of `GET {backendUrl}/serve/all/auto/{projectId}` returning
`{ globalVariables: [], microfrontends: [{ slug: 'example-remote', url: 'http://localhost:4301/parcel.js', ... }] }`,
build the host against it and check in a browser: `/home/` renders, "Example remote" mounts the
parcel and its button counts, "Home" unmounts it, a second visit starts from 0, no console errors.
